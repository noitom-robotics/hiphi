Overview

From FrameNet-guided motion units to humanoid-ready MoCap.

HiPHI treats data collection as coverage-guided motion-space design: lexical FrameNet seeds become concrete, repeatable, high-precision optical MoCap sequences with object state when the motion requires it.

Frame-LU construction

FrameNet seeds become coverage-guided motion construction.

HiPHI uses FrameNet frames and lexical units as motion seeds. Each Frame-LU expands through controlled realization factors such as speed, direction, posture, body-part involvement, and object/contact conditions.

Object-grounded motion

Object state is part of the motion record.

HiPHI records synchronized human motion, object trajectories, and object meshes. Object-interaction is therefore physically grounded rather than a text label attached after capture.
